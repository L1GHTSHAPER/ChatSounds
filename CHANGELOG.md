# Changelog

## 1.0.2

- Updated the package icon and README with the rounded LightShaper logo and black, white and purple visual style.
- Plugin behavior is unchanged.

## 1.0.1

- Added the public GitHub repository link to the package website and README.
- Published source code and packaged downloads on GitHub. Mod behavior is unchanged.

## 1.0.0

- Initial release.
- Sounds for new messages in the global chat and the local chat, and a separate sound for messages that mention your name or your keywords.
- Each of the three has its own on/off switch, sound, volume, play condition (always / tab not visible / game in background) and cooldown.
- 8 built-in sounds, the game's own sound effects and pomodoro bells, and your own `.wav` / `.ogg` / `.mp3` files from `BepInEx/config/ChatSounds`.
- In-game settings window (F9 or `/chatsound`), `/chatsound` (`/csnd`) chat commands, Left Shift + F9 to turn all sounds on/off.
- Quiet mode for focus sessions, optional scaling by the game's Master volume.
- Config edits made in the mod manager apply while the game is running.
- English and Russian interface.
- Optional integration with CommandAPI (`/help` listing, CommandTypeahead suggestions).
